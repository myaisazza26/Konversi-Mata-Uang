# Konversi-Mata-Uang
Konverter Mata Uang adalah aplikasi konversi nilai tukar untuk 30 mata uang. Pengguna memasukkan jumlah, memilih mata uang asal dan tujuan, lalu memperoleh hasil seketika beserta kurs per satuan. Tersedia papan kurs untuk membandingkan satu jumlah di berbagai mata uang, riwayat konversi, dan kurs acuan yang dapat disesuaikan. Kurs hanya perkiraan.
